# Farhan Fitness — Floor Safety Rules (Mock)

## Non-Negotiables

- Clips on all barbell work outside warm-up empty bar drills
- No headphones that block coach cues during class
- Collars required when loading above 135 lb / 60 kg (mock threshold)

## Spacing

- One working athlete per rack side during peak; share only when coaches pair stations

## Emergency

- AED locations: front desk wall and Studio B entry (mock)
- Incident reporting: notify GM same day via incident@farhanfitness.com (illustrative)

## Youth Rules

- Ages 13–17 require guardian-signed waiver; coach must approve max attempts on main lifts (mock).
