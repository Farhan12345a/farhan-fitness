# Farhan Fitness — Passes and Membership SKUs (Mock)

## Digital Pass Overview

All memberships and class packs are managed electronically through the member app and billing profile (mock). No paper punch cards.

## Pass Identifiers (Mock)

### Member ID Format
**Structure:** FF-########

| Component | Meaning |
|-----------|---------|
| FF | Farhan Fitness prefix |
| 8 digits | Unique member number |

### Booking Code (Class Hold)
- 6 alphanumeric characters (mock)
- Example: STRONG7
- Used to confirm waitlist promotion when a spot opens

## Pass Types

### Standard Monthly Membership
- Auto-renew; cancellation per terms of agreement (mock)

### Class Pack
- 10 visits; expires 90 days from purchase (mock)

### Day Pass (Visitor)
- Single calendar day access during staffed hours
- Must complete waiver digitally (mock)

### Corporate Bundle
- Billed to employer; roster managed by partnerships team (illustrative)

## Pass Validity (Mock)

| Type | Validity |
|------|----------|
| Monthly | Active billing cycle |
| Class pack | 90 days from purchase |
| Day pass | Date of purchase only |
